# math/anchor-absent-condition

The first bar anchors the calculation. Absence is not a true reset condition,
so the next bar contributes normally: (10 * 2 + 20 * 6) / 8 = 17.5.
The third bar gives (20 + 120 + 80) / 10 = 22. Dropping the second bar because
its condition is absent produces a different result on both later bars.
