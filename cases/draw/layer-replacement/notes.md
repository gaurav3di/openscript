# draw/layer-replacement

Three labels created on bars 0 and 1, the second deleted on bar 4.

## What it pins

`compiled-program.md` section 11: the whole set is handed over and replaces what
came before, in creation order, so a deleted object needs no instruction of its
own: it is not there.

## Reference

Worked out by hand by the author of this case from the script's own arguments,
the defaults `stdlib.md` section 14.4 prints beside each creation call, and the
channel values of `spec/colours.json`, under this repository's licence.
