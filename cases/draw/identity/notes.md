# draw/identity

A line created once and moved on every bar.

## What it pins

`language.md` 5.4 and `stdlib.md` 14.4: the `var` holds the object, not a copy
of it, so the script holds one object throughout and its second anchor is the
last bar's.

## Reference

Worked out by hand by the author of this case from the script's own arguments,
the defaults `stdlib.md` section 14.4 prints beside each creation call, and the
channel values of `spec/colours.json`, under this repository's licence.
