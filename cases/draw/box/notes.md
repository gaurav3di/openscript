# draw/box

A box with its defaults and one with every argument written.

## What it pins

`stdlib.md` 14.4: a box is two anchors; with nothing written it has no border
colour and no fill, an opacity of 0.12, a width of 1, no caption, `white` text
and no tooltip. The second box reaches a bar back and a bar forward in time.

## Reference

Worked out by hand by the author of this case from the script's own arguments,
the defaults `stdlib.md` section 14.4 prints beside each creation call, and the
channel values of `spec/colours.json`, under this repository's licence.
