# table/absent-cell

A cell whose text is a close twenty bars back over eight bars, and one whose
background is none.

## What it pins

`language.md` 6.7: absence reaching a drawing surface is a gap, so the first
cell's text is absent, which a host renders blank, and the second cell has no
background.

## Reference

Worked out by hand by the author of this case from the script's own arguments,
the defaults `stdlib.md` section 14.3 prints beside `cell`, and the
channel values of `spec/colours.json`, under this repository's licence.
