# table/per-bar-update

Each bar writes its own row.

## What it pins

`compiled-program.md` 2.8: the cells are an output buffer emptied at the start
of every execution of a bar, so the grid holds row 7 and none of the rows
earlier bars wrote.

## Reference

Worked out by hand by the author of this case from the script's own arguments,
the defaults `stdlib.md` section 14.3 prints beside `cell`, and the
channel values of `spec/colours.json`, under this repository's licence.
