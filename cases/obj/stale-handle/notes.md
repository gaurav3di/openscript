# obj/stale-handle

A line deleted on bar 2 and recoloured on bar 4 through the name that still
holds it.

## What it pins

`stdlib.md` 14.4 and `errors.md` OS4005: a setter given a deleted object stops
the bar at the setter, line 9, on bar 4. The name was never set to `none`,
which is the fix the entry gives.
