# obj/array-of-objects

A box on every bar, kept in an `array<box>`, trimmed to the three newest.

## What it pins

`language.md` 5.4 and 14.1: an object is an ordinary value an array can hold, and
the script deletes the object and then removes the element, so the array and the
drawn set stay the same size.

## Reference

Worked out by hand by the author of this case from the script's own arguments,
the defaults `stdlib.md` section 14.4 prints beside each creation call, and the
channel values of `spec/colours.json`, under this repository's licence.
