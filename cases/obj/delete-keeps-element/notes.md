# obj/delete-keeps-element

A box pushed on every bar and the first deleted on bar 3 without being removed.

## What it pins

`language.md` 5.4: the array keeps growing by one a bar while the drawn count
falls one behind it from bar 3, because deletion ends the object and not the
element that names it.

## Reference

Worked out by hand by the author of this case from the script's own arguments,
the defaults `stdlib.md` section 14.4 prints beside each creation call, and the
