# obj/table-same-object

A grid kept in a `var` on bar 0 and written through that name on every bar.

## What it pins

`language.md` 5.4: the call site returns the same object on every bar, so the
name kept from bar 0 is still the grid on bar 7 and the cell it writes is the
grid's.

## Reference

Worked out by hand by the author of this case from the script's own arguments,
the defaults `stdlib.md` section 14.3 prints beside `cell`, and the
channel values of `spec/colours.json`, under this repository's licence.
