# obj/identity-equality

Two labels with the same anchor and text, and a second name for the first.

## What it pins

`language.md` 5.4 and 9.3: `==` between objects is identity, so a second name
for one object is equal to it and a second object with every property the same
is not.

## Reference

Worked out by hand by the author of this case from the script's own arguments,
the defaults `stdlib.md` section 14.4 prints beside each creation call, and the
channel values of `spec/colours.json`, under this repository's licence.
